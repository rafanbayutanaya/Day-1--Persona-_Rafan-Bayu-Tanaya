# Day-1--Persona-_Rafan-Bayu-Tanaya
Sebuah repository (atau biasa disingkat repo) adalah tempat penyimpanan digital terpusat yang digunakan untuk menyimpan, mengelola, dan melacak seluruh file proyek beserta riwayat perubahannya (versi kode).

Dalam pengembangan perangkat lunak, repository umumnya menggunakan sistem pengontrol versi seperti Git (misalnya di platform seperti GitHub, GitLab, atau Bitbucket).

Fungsi Utama Repository:
Penyimpanan Terpusat: Menyimpan seluruh kode sumber (source code), aset, dokumentasi, dan konfigurasi proyek dalam satu tempat.

Riwayat Versi (Version Control): Mencatat setiap perubahan yang dilakukan, siapa yang mengubahnya, dan kapan perubahan itu terjadi, sehingga Anda dapat kembali ke versi sebelumnya jika terjadi kesalahan.

Kolaborasi Tim: Memungkinkan banyak pengembang untuk bekerja pada proyek yang sama secara bersamaan tanpa saling menimpa pekerjaan (merge conflict dapat dikelola dengan mudah).

Prompt adalah instruksi atau masukan yang Anda berikan kepada model untuk mendapatkan hasil tertentu. Bentuknya bisa beragam, mulai dari pertanyaan sederhana, kata kunci, hingga instruksi yang rumit, atau potongan kode.

Git adalah version control system—yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file. Git diciptakan oleh Linus Torvalds pada tahun 2005. Alat ini dirancang untuk mencatat setiap perubahan yang terjadi pada file.

Working directory/tree adalah salinan dari satu versi proyek yang sedang kamu kerjakan. File-file di dalamnya diambil dari database yang tersimpan di direktori Git, kemudian ditempatkan di komputer agar dapat digunakan atau dimodifikasi.

Staging area adalah file yang umumnya berada di dalam direktori Git dan berfungsi untuk menyimpan informasi mengenai perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya. Dalam istilah teknis Git, staging area disebut sebagai index.

Git directory adalah tempat Git menyimpan metadata dan object database dari sebuah proyek. Bagian ini merupakan komponen terpenting dalam Git karena berisi seluruh informasi yang dibutuhkan Git untuk mengelola proyek. Ketika kamu melakukan clone repository dari komputer lain, bagian inilah yang akan disalin.

Git = Sistem version control terdistribusi (DVCS) yang digunakan untuk melacak dan mengelola perubahan kode secara lokal.

Github = Platform berbasis web yang digunakan untuk menyimpan repository Git secara online dan mendukung kolaborasi.
